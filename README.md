# Programming Your GPU with OpenMP

This is a hands-on tutorial that introduces the basics of targeting GPUs with OpenMP through a series of examples.

Starting with serial code, the tutorial takes you through parallelising, exploring the performance characteristics, and optimizing the following small programs:

* `vadd` – A simple vector addition program, often considered the "hello world" of GPU programming.
* `pi` – A numerical integration program that calculates and approximate value of π.
* `jac_solv` – A Jacobi solver; a relaxation method for solving a system of linear equations.
* `heat` - An explicit finite difference 5-point stencil solver for the heat diffusion equation.
* `mm_testbed` - Matrix multiplication functions including matrix generation and testing.
